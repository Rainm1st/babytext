一、比赛与赛道

项目说明
赛事 BabyLM Challenge — 在有限语料上预训练小模型，评测语言能力与样本效率
赛道 Strict：固定约 100M 词训练预算与官方语料组合
官方资源 语料：BabyLM-2026-Strict · 基线：BabyLM-community · 评测：babylm-eval/strict
核心指标 Zero-shot 平均、Finetune 平均、综合 Text Average（以 leaderboard 为准）
两条技术路线 GPT-2 causal：自回归 + 可选混合 mask（本仓库 train_hybrid_gpt2.py）
GPT-BERT mntp：掩码为主 + 少量因果（官方 ltgoslo/gpt-bert，榜一 baseline 族）

  --model_path_or_name mask10_rerun_best \
