run5 教师模型增广计划（最新）

目标：在不破坏 strict 主干语料的前提下，用合规教师模型对 mnli/rte/wsc/qqp 做高质量增广，重点修复 RTE/WSC/QQP 的塌缩问题。

教师模型白名单（按你提供的规则）

  • Llama 家族：Llama 3.1 8B Instruct、Llama 3.2 3B Instruct、Llama 3.2 1B Instruct
  • Qwen 家族：Qwen 2.5 / Qwen 3 / Qwen 3.5，上限 9B 参数
  • 任意 <1B 的语言模型可用

run5 默认推荐：主教师 A = Qwen/Qwen2.5-7B-Instruct，主教师 B = meta-llama/Llama-3.1-8B-Instruct。

已生成脚本

脚本用途
experiments/gpt2-masked-objective/scripts/teacher_generate_run5.py 双教师生成原始增广样本（JSONL）
experiments/gpt2-masked-objective/scripts/build_run5_mixed_dataset.py 双教师一致性过滤 + 去重 + 按比例混合，导出 run5 训练文本
experiments/gpt2-masked-objective/scripts/train_mask10_run5.sh 自动生成 run5 配置并启动训练（GPU0）

run5 目录约定

  • /data0/language/babylm_runs/mask10_run5/data_raw：教师原始输出
  • /data0/language/babylm_runs/mask10_run5/data：过滤后数据与最终 train.txt
  • /data0/language/babylm_runs/mask10_run5/logs：训练日志
  • /data0/language/babylm_runs/mask10_run5/checkpoints：checkpoint

执行顺序（服务器）

cd ~/babytext/experiments/gpt2-masked-objective

# 1) 教师生成（可先小规模试跑）
python scripts/teacher_generate_run5.py \
  --model-a Qwen/Qwen2.5-7B-Instruct \
  --model-b meta-llama/Llama-3.1-8B-Instruct \
  --max-samples-per-task 300 \
  --variants-per-sample 1 \
  --use-bf16

# 2) 构建混合数据（默认目标原始:合成为 7:3）
python scripts/build_run5_mixed_dataset.py \
  --orig-ratio 0.7

# 3) 启动 run5 训练
bash scripts/train_mask10_run5.sh

关键过滤策略（已在脚本实现）

  • 双教师必须都能解析出 JSON 输出（否则丢弃）
  • 双教师预测标签都必须与原标签一致（否则丢弃）
  • 双教师生成文本需一致（保守一致性策略）
  • 对原始训练文本和合成文本做规范化去重
  • 混合阶段限制合成比例，避免 synthetic 淹没原始分布

训练方向建议（run5）

  • 保持 masked_alpha=0.10，先验证数据增广本身收益
  • 先小规模（每任务 300）跑通，再放大到 600~1000
  • 训练后必须跑官方 strict pipeline（zero-shot + finetune）再与 run3/run4 判优
