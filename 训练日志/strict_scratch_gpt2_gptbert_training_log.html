Strict 赛道 · 从零预训练实验日志

双路线：GPT-2 因果 LM（causal） 与 GPT-BERT 掩码主线（mntp）。本文档随训练更新结果。

文档版本：2026-05-18（初稿）　仓库：github.com/Rainm1st/babytext

一、问题与目标

  • 在 BabyLM 2026 Strict 预算下，仅使用官方语料，分别从随机初始化训练两套模型。
  • GPT-2 线：提交评测 backend 为 causal。
  • GPT-BERT 线：提交评测 backend 为 mntp。
  • 训练完成后在此表同步：验证损失 / 官方 zero-shot+finetune / leaderboard（按实际可得的指标填写）。

二、GPT-2 strict scratch（babylm-strict-scratch/）

2.1 模型与数据

项说明
架构HuggingFace AutoConfig.from_pretrained("gpt2") + AutoModelForCausalLM.from_config，随机初始化（不加载 OpenAI / BabyLM 预训练权重）
Tokenizergpt2（仅词表）；若缺 pad 则添加 <|pad|> 并 resize_token_embeddings
数据目录内全部 *.train.txt；按块拼接为长度 max_sequence_length（默认 512）的 CLM 样本
混合比例可选 source_proportional_batches + source_word_counts，使 batch 内各文件比例贴近子语料词数占比

2.2 训练策略

项默认 / 配置
损失标准因果语言建模（next-token / 块内对齐的 labels）
优化器AdamW；weight decay 分组（无 decay：bias/LayerNorm 等）
学习率调度Cosine；warmup_ratio 默认 0.06
精度配置 mixed_precision: bf16（无 GradScaler）；fp16 时启用 Scaler
Epoch 上限代码强制 ≤ 10（赛事）
有效 batchbatch_size_per_device × GPU 数 × gradient_accumulation_steps

2.3 日志、断点、W&B

  • 进度条：每 epoch tqdm；数据集 map 阶段带描述。
  • 断点：training_state.pt（优化器、调度器、scaler、global_step、RNG、epoch 内 batch 进度）；checkpoints/epoch_*、step_*、best。
  • 续训：./run_train.sh config.json ./outputs/RUN --resume 或 --resume-from ./outputs/RUN（须与 --output-dir 同一路径）。
  • W&B：配置文件 use_wandb（默认 false）；需 pip install wandb。

三、GPT-BERT strict scratch（gpt-bert-masked-focus/scripts/ + ltgoslo/gpt-bert）

3.1 模型与数据

项说明
代码官方 pretraining/train_100m.py（需 torchrun）
配置configs/base.json（vocab_size=16384，768×12）；禁止与 16k tokenizer 混用 small.json
初始化不传 --checkpoint_filename 时为 随机初始化 Bert(args)
TokenizerTokenizer.from_file(tokenizer.json)，通常由 HF babylm-baseline-100m-gpt-bert-masked-focus 导出
数据预 tokenize 的 .bin（04b_tokenize_babylm_strict.sh 由 Strict 文本生成）

3.2 训练策略

项说明
主目标掩码跨度 + 随机替换（mask_p_start/end、mask_random_p、mask_keep_p）+ 辅助 z-loss
单卡 hybridhybrid_numerator=1、hybrid_denominator=1 → 全程 masked 分支（多卡 16 张时可接近官方 15/16 + 1/16）
优化器LAMB；默认 lr=0.007；warmup/cooldown 比例各约 1.6%
步数环境变量 GPT_BERT_MAX_STEPS（脚本默认 20000）；需结合显存调整 GPT_BERT_LOCAL_BATCH 等
序列长度脚本默认 seq_length=128；训练后段官方脚本可能按进度放大（见 src）

3.3 日志、断点、W&B

  • 进度条：train_100m.py 内 tqdm（Train / Valid）。
  • 断点：每 save_every 生成 {name}.bin 与 {name}_state_dict.bin；续训用 *_state_dict.bin（含优化器与步数）。
  • 续训：export GPT_BERT_RESUME_STATE=/path/to/*_state_dict.bin 后执行 06_train_single_gpu_torchrun.sh。
  • W&B：默认 WANDB_DISABLED=true；补丁 09_patch_*（dataloader）、10_patch_*（wandb stub）。

3.4 运行参数备忘（服务器）

四、本地 Windows 上传（PowerShell 注意）

勿用变量名 $Host：在 PowerShell 中 $Host 是内置只读对象，用作 SSH 目标会变成无效主机名。

请改用例如 $SshHost：

$Port = 25123
$SshHost = "language@8.153.12.93"
$Src = "D:\AAAprojects\babylava\BabyLM-community\experiments"

scp -P $Port -r "$Src\babylm-strict-scratch" "${SshHost}:~/babytext/experiments/"
scp -P $Port -r "$Src\gpt-bert-masked-focus"   "${SshHost}:~/babytext/experiments/"

SSH 登录：ssh -p 25123 language@8.153.12.93

五、环境与常见问题

  • GPT-BERT：词表 16k 必须与 base.json 一致，否则 CUDA device-side assert。
  • GPT-BERT 导出给 HF / babylm-eval：除 .bin 外通常还需 config.json 与 tokenizer 文件，按评测仓库要求补齐。
  • 两台实验独立：勿将 GPT-BERT checkpoint 载入 GPT-2 脚本或相反。
