一、概念：Causal / GPT-BERT / Masked Focus / MNTP

术语含义
Causal（因果 LM）GPT-2 路线：从左到右预测下一 token；评测后端常标 causal。
GPT-BERT同一 Transformer 堆叠，混合 掩码目标（MNTP/MLM 味） 与 少量因果目标；官方 repo：ltgoslo/gpt-bert。
Masked Focus训练时绝大多数 step 走掩码分支（榜一 baseline 约 93.75% masked / 6.25% causal）。
MNTPMasked Next Token Prediction；leaderboard 上该后端分数往往高于 pure causal。
官方权重BabyLM-community/babylm-baseline-100m-gpt-bert-masked-focus（约 120M 参数）。

二、为什么不能把 GPT-BERT 权重直接塞进 train_hybrid_gpt2.py？

问：都在官方 Strict 数据上训，为何不能用 leaderboard 最好的 baseline 当起点？

答：数据可以相同，但架构与训练循环必须匹配。当前 train_hybrid_gpt2.py 是 AutoModelForCausalLM + 自定义 hybrid mask；GPT-BERT 是另一套模型定义与双目标（需 ltgoslo/gpt-bert 的 pretraining/train_*.py）。换线 = 新代码栈 + 新评测后端（提交时 --backend mntp 或官方说明）。

四、官方提交（collate_preds）

问：怎么提交 run3？

答：在 babylm-eval/strict 下生成 predictions 汇总文件后上传 leaderboard。GPT-2 系用 --backend causal（不是 main）。

cd ~/babytext/experiments/babylm-eval/strict
python -m evaluation_pipeline.collate_preds \
  --model_path_or_name mask10_rerun_best \
  --backend causal \
  --track strict

若提示 AoA 缺失：多为 warning，可先 find 提交 JSON；要完整分可补跑 zero-shot 后再 collate。

五、策略决策：为何考虑 GPT-BERT 线

  • GPT-2 线在 strict 上提分遇瓶颈；教师模型增广（run5）短期难高质量落地。
  • Leaderboard 上 Baseline-gpt-bert-masked-focus (mntp) Text Average 高于纯 GPT-2 baseline。
  • 计划：用官方 GPT-BERT 权重 + 官方训练代码，在 Strict 语料上继续预训练；评测走 mntp。

注意：需单独 tokenize 语料（gpt-bert 仓库 corpus_tokenization），不能直接用 *.train.txt 喂给原训练脚本。
