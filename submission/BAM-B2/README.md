# BAM-B2 submission snapshot

This directory mirrors the final public model's non-weight files from [Recor2d/BAM-B2](https://huggingface.co/Recor2d/BAM-B2), commit `b1a7488` (`Upload BAM B2 from-scratch final model`).

Included:

- `config.json`
- `configuration_gpt_bert.py`
- `modeling_gpt_bert.py`
- `special_tokens_map.json`
- `tokenizer.json`
- `tokenizer_config.json`

The 385 MB `model.safetensors` file is intentionally omitted. Hugging Face remains the canonical source for weights and future model-repository revisions.
